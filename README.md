## 功能

- 多账号添加、编辑、选择登录
- 套餐与免费用量识别
- 号池加密导入导出分发
- 流量用尽后自动切号
- 开机自启与托盘图标常驻
- 流量配额汇总和账号配额展示
- Android / Windows 跨平台支持
