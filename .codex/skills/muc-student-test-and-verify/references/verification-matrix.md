# 验证矩阵

## React 界面和前端状态

- `pnpm build`
- `pnpm lint`

## Rust 领域、应用、基础设施

- `cargo check`
- 有相关测试就跑 `cargo test`

## React、Tauri command 和 Rust 对接

- `pnpm build`
- `pnpm lint`
- `cargo fmt --check`
- `cargo check`
- 必要时 `cargo test`

## Tauri 打包、托盘、自启、Windows 行为

- `cargo fmt --check`
- `cargo check`
- `cargo test`
