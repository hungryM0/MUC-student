# 验证矩阵

## React 页面、组件、hook、样式

- `pnpm build`
- `pnpm lint`

## Rust 领域、应用、基础设施

- `cargo fmt --check`
- `cargo check`
- 有相关测试就跑 `cargo test`

## React、Tauri command、Rust DTO 对接

- `pnpm build`
- `pnpm lint`
- `cargo fmt --check`
- `cargo check`
- 必要时 `cargo test`

## 网络、parser、持久化、迁移、自动切号

- `cargo fmt --check`
- `cargo check`
- `cargo test`

## Tauri 打包、托盘、自启、Windows 行为

- `cargo fmt --check`
- `cargo check`
- `cargo test`
- 发布前加 `pnpm build` 和 `cargo build --release`
